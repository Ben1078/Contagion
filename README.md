# Contagion

Bare Eclipse project scaffold for the CS 2420 team project.

The `contagion` package contains empty class shells for:

- `Country`
- `TravelRoute`
- `PandemicNetwork`
- `Disease`
- `CureSystem`
- `GraphTools`
- `SpreadSimulator`

The project is configured for Java 22 and includes `algs4.jar`. Implementation
will be completed by the team.
